# JRAデータ取得

用途が2つあります。まずどちらかを判断してください。

| 用途 | 使うコマンド |
|------|-------------|
| 学習データを貯めたい（一般レースを含む過去レースをまとめて） | `collect`（A） |
| 特定のレース1つを予想したい（今週開催の出馬表） | `fetch-jra` + `extract-html-only`（B） |

依頼文に「学習」「過去レース」「まとめて」「期間」「〇年〇月」が含まれればA、
URLが提示されていればBです。判断がつかない場合は AskUserQuestion で確認してください。

---

## A. 一般レースを含む過去レース結果の一括収集

```bash
# まず1か月ぶんから始める
bun start collect --month 2024-12

# 期間を指定する場合
bun start collect --from 2024-01-01 --to 2024-12-31

# 動作確認（DBに書き込まない）
bun start collect --month 2024-12 --limit 5 --dry-run
```

実行前に必ず伝えること:

- リクエスト間隔はプロセス全体で**最低2秒**（短縮できない）。
  1か月ぶん（約300レース）でおよそ30分、1年ぶんで数時間かかる
- 取得したHTMLは `data/raw/jra/` にキャッシュされ、同じページは二度取得しない
- 中断しても `collection_log` の記録から続きを再開できる（同じコマンドを再実行するだけ）
- 何度実行しても行は増えない（冪等）

収集後は必ず蓄積状況を表示してください:

```bash
bun start data-status
```

レース結果ページから取れない項目（事前オッズ・血統・馬主）については
`docs/COMMANDS.md` の `collect` の節を参照してください。

> `data-status` の「単勝オッズ」null率が高いのは**正常**です。
> `race_entries.win_odds` は将来の出馬表収集で埋める列で、
> レース結果ページから取れる確定オッズ（1着馬のみ）は
> `race_results.final_win_odds` にだけ保存しています
> （`win_odds` に入れると「オッズがある＝勝ち馬」というリークになるため）。
> 市場系の特徴量は全馬ぶん取れる `popularity`（人気順位）が主軸です。
>
> 旧版で収集したDBに確定オッズが `win_odds` に混入している場合は、
> `bun start rebuild-stats` でクリアできます。

## B. 特定URLの出馬表を取得・抽出

## 引数

- ユーザーが指定したJRA URL（出馬表ページ等）

## 実行手順

### 0. URL確認（重要）

URLが指定されていない場合、AskUserQuestion ツールを使ってURLを入力してもらってください：

- 質問: 「JRAの出馬表URLを入力してください」
- ヘッダー: 「URL入力」
- 選択肢:
  - 「出馬表ページ」: JRAの出馬表ページのURLを入力

ユーザーが「Other」で直接URLを入力した場合は、そのURLを使用してください。

### 1. HTML取得

```bash
bun start fetch-jra "<URL>"
```

※ URLが未指定だった場合は、上記ステップ0で取得したURLを使用

### 2. データ抽出

```bash
bun start extract-html-only data/jra-page.html
```

### 3. DB保存の確認

データ抽出完了後、AskUserQuestion ツールを使って以下のように確認してください：

- 質問: 「データベースに保存しますか？」
- ヘッダー: 「DB保存」
- 選択肢:
  - 「保存する」: スコア計算・予想機能が使えるようになります
  - 「保存しない」: JSONファイルのみ保存（data/horse-extracted-data.json）

### 4. DB保存する場合

ユーザーが「保存する」を選択した場合、以下を実行：

```bash
bun start import-url data/horse-extracted-data.json
```

## DB保存のメリット

保存すると以下の機能が使えます：

| 機能 | 説明 |
|------|------|
| race-list スキル | 登録済みレースの予想実行 |
| スコアリング | 10要素の総合評価（直近成績・コース適性・距離適性・上がり3F・G1実績・ローテ・騎手能力・馬場適性・枠順効果・調教師） |
| 機械学習予測 | 蓄積データから単勝・複勝確率を予測 |
| 血統分析 | 種牡馬別の成績統計 |
| 過去レース蓄積 | 前走データが他の馬の分析に活用される |

## 使用例

```
# A: 学習データの一括収集
2024年12月のレースを収集して

# B: 特定レースの出馬表
データ取得 https://www.jra.go.jp/JRADB/accessD.html?CNAME=...
```

## 出力形式オプション

デフォルトは `detailed`（詳細表示）

- `detailed` - 全項目表示
- `summary` - 要約表示
- `csv` - CSV形式
