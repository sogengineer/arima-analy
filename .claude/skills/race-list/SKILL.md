# レース一覧表示と予想実行

登録済みのレース一覧を表示し、予想したいレースを選択できます。

## 位置づけ（重要）

- **ML確率が主**: 単勝確率（レース内合計100%）と複勝確率（合計300%）が予想の軸。
- **ルールベース10要素は「理由の内訳」**: 順位付けの根拠ではなく、
  なぜその馬が高いのか／低いのかを人間に説明するための材料として使う。
- **採用ゲート未通過なら主従が逆転する**: `bun start ml --validate` の
  採用ゲートが ❌ の場合、順位付けはルールベース総合スコアを主とし、
  ML確率は参考値として併記する（後述）。

## 手順

### 1. レース一覧を取得

```bash
bun start score --list
```

### 2. ユーザーに質問

レース一覧を表示したら、AskUserQuestion ツールを使って以下のように質問してください：

- 質問: 「どのレースを予想しますか？」
- ヘッダー: 「レース選択」
- 選択肢: レース一覧から上位4件を選択肢として提示（ID: レース名 形式）

### 3. 採用ゲートを確認（最初に1回）

```bash
bun start ml --validate
```

出力の「採用ゲート」を読み、以下のどちらの方針で進めるかを決めてください。

| ゲート判定 | 予想の主軸 | 表示方法 |
|-----------|-----------|---------|
| ✅ 通過（log loss が市場オッズを下回り、top-1 がルールベースを上回る） | **ML確率** | ML順で並べ、10要素は理由として添える |
| ❌ 未通過 / データ不足で検証不能 | **ルールベース10要素** | スコア順で並べ、ML確率は「参考」と明記して併記 |

ゲートが未通過、または「walk-forward には最低10レース必要です」等の
データ不足メッセージが出た場合は、**必ず**予想の冒頭に
「ML は採用基準を満たしていないため、順位はルールベースを主としています」と書いてください。

### 4. ML予測を実行

```bash
bun start ml --race <選択されたレースID>
```

出力される列:

| 列 | 意味 |
|----|------|
| 単勝 | ML の単勝確率（レース内合計100%） |
| 複勝 | ML の3着以内確率（レース内合計300%） |
| 市場 | 控除率補正済みの市場暗黙勝率。全馬にオッズが揃っているレースはオッズから、揃っていなければ**人気順位**から算出 |
| ルール | ルールベース10要素の総合スコア（0-100） |

「単勝 − 市場」が正の馬は、**モデルが市場より高く評価している**馬です（妙味候補）。

> 過去レース結果ページには全馬の事前単勝オッズが無いため、
> 蓄積データでは `race_entries.win_odds` が大半 NULL です（異常ではありません）。
> そのため市場系の指標は **人気順位（`popularity`）** を主軸にしています。
> `backtest` / `ml --validate` の出力に「算出元: 単勝オッズ N件 / 人気順位 M件」が出るので、
> 市場との比較を語るときはどちらで算出したかを併記してください。

### 5. ルールベースの内訳を取得

```bash
bun start score --race <選択されたレースID>
```

10要素（直近成績 / コース適性 / 距離適性 / 上がり3F / G1実績 / ローテ適性 /
騎手能力 / 馬場適性 / 枠順効果 / 調教師）の内訳を、予想理由の説明に使います。

- 調教師スコアは Orchestrator 未実装のため現状は全馬0点です。0点を「弱い」と解釈しないこと。
- 重みの正は `src/constants/ScoringConstants.ts` です。
- 10要素は ML の特徴量の一部でもあります（`ruleScores`）。
  「10要素だけが ML の特徴量」ではありません。ML は市場オッズ・馬体重・斤量・
  通算成績・前走情報・レース内相対化も使います。

## やってはいけないこと

- ML確率を「的中率」と言い換えないこと（確率であって保証ではない）。
- 採用ゲート未通過なのに ML順を主軸として提示しないこと。
- 特徴量の重要度を固定で決めつけないこと。`ml --train` の
  「特徴量寄与度（標準化係数）」の実出力から述べること。
- 存在しない特徴量（中山複勝率、過去3走偏差値など）を説明に使わないこと。

## 出力順序

1. 最終予想（採用ゲートの状態を明記）
2. ML確率 × 市場 × ルールベースの比較表
3. 予想理由（ML確率が結論、10要素が内訳）
4. 穴馬候補
5. 懸念点・リスク
6. 買い目提案
