# 血統分析

種牡馬一覧と統計情報を表示します。

## 実行コマンド

```bash
bun start show-sires
```

## 出力内容

- 種牡馬名
- 芝ダ・距離カテゴリ別の勝利数・出走数・勝率（統計が登録されている場合）

## 分析ポイント

- 中山芝2500mに強い血統
- 重馬場適性のある血統
- 長距離適性の遺伝傾向
