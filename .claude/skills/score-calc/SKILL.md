# スコア計算

指定したレースの出走馬に対して10要素スコアリングを実行します。

## 引数

- レースIDまたはレース名（部分一致）。ユーザーの発言から抽出する

## スコア配分

重み配分は `src/constants/ScoringConstants.ts` の `SCORE_WEIGHTS` で一元管理されています。

| 要素 | 重み |
|------|------|
| 直近成績 | 22% |
| コース適性 | 15% |
| 距離適性 | 12% |
| 上がり3F能力 | 10% |
| G1実績 | 5% |
| ローテ適性 | 10% |
| 騎手能力 | 8% |
| 馬場適性 | 5% |
| 枠順効果 | 5% |
| 調教師 | 8% |

## 実行コマンド

```bash
bun start score --race "<レースIDまたはレース名>"
```

## 使用例

```
スコア計算 1
スコア計算 有馬
```

## 出力

- 総合スコアランキング（馬番順位、各要素スコア）
- 上位5頭の詳細分析（強み・課題）
- スコア分布（有力候補/注目馬/一般馬/厳しい）

## 事前確認

レースIDを確認するには race-list スキルを実行してください。
